# Extension Icons

This directory should contain the following icon files for the ElysianAI extension:

- icon16.png (16x16 pixels)
- icon32.png (32x32 pixels) 
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

You can create simple placeholder icons using any image editor or use an online icon generator. The icons should represent the ElysianAI brand - consider using a simple "AI" or "E" logo with a modern tech aesthetic.

For development purposes, you can use any placeholder images and replace them later with proper branded icons.
